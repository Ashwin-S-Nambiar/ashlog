## Overview
The **backend** (server side) is the pat that we can't see. It is the internet working or behind the scenes of the the application or website. This includes stuff like **server**, **database**, etc.

Backend is a crucial part of any [[notes/Web Development]] project.

## What a backend developer does?
- They write server side code.
- Make use of databases like [[notes/Tech Stack/MongoDB]], [[notes/Tech Stack/PostgreSQL]].
- Ensure that server-side-code is optimized enough to handle large volumes of traffic.
